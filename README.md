# 前后端模拟台 · vibe-coding-glossary

**组件看得见 · 技术讲得清**

一个纯 HTML 单文件的前端组件实验室：收录 **46+ 个真实可交互的 UI 组件与交互行为演示**，每个组件都附带技术解释和 vibe coding 例句，适合边看边学、随手抄走。

## 快速开始

直接用浏览器打开 `index.html` 即可，无需构建、无需依赖。

## 内容分类

页面按以下主题组织组件演示：

| 分类 | 内容 |
| --- | --- |
| 页面骨架与容器 | 布局、栅格、卡片、页头页脚等容器类组件 |
| 用户怎么在页面里走 | 导航、菜单、标签页、面包屑、分页等 |
| 让用户把信息交给你 | 表单、输入、选择、上传、校验等 |
| 系统怎么告诉用户「发生了什么」 | 弹窗、提示、Toast、空状态、加载等反馈组件 |
| 把数据摆给用户看 | 表格、列表、统计卡片、图表容器等数据展示 |
| 行为与全局 | 交互状态、动效、暗色模式等行为演示 |
| 后端技术栈 | 常见后端概念的对照说明（以组件示例呈现） |

> 每个演示都是**真实可交互**的（点击、输入、拖拽、开关等），而非静态截图。

## 项目结构

```text
index.html                    全部内容（组件 + 解释 + 例句，单文件）
assets/                       少量静态资源
```

## 技术栈

- 原生 HTML + CSS + JavaScript（单文件，零依赖）
- 无构建步骤，可直接在浏览器运行，也适合快速复制到任意项目
