# 全栈学习库 · vibe-coding-glossary

**技术认知先行 · AI 协作贯穿 · 工程结果可验收**

一个面向初学者的全栈技术认知与 AI 协作训练库：用 **12 个知识模块**建立从页面、网络、后端、数据、身份、工具链到部署的技术地图，再用一个行程管理主线项目把知识串成真实交付。

学习者先理解技术解决什么问题、自己做方案判断，再让 AI 分步实现、检查差异、运行验证和修复故障。页面保留 50+ 个真实可交互 demo，每个重点主题都配有学习动作、工程提醒、AI 任务和验收标准。

**[在线体验](https://tuanzi188.github.io/vibe-coding-glossary/)**

## 快速开始

直接用浏览器打开 `index.html` 即可，无需构建、无需依赖。

## 学习结构

项目由“知识地图、贯穿式 AI 协作、主线实践”三条线组成：

- **知识地图**：页面基础、JavaScript、组件化前端、前端工程、网络与浏览器、Python、后端工程、数据与存储、身份与权限、工具链与 Git、部署与运维。
- **AI 协作中心**：任务拆解、上下文整理、修改边界、代码差异、运行验证、证据化排错和结果验收。
- **主线实践**：从静态行程页面开始，逐步加入交互、接口、数据、登录、测试、日志和部署。

推荐顺序与知识地图分开：工具链提供第一天的最小起步，完整工具链在后续系统学习；AI 协作和主线实践从第一步就参与。

> 每个演示都是**真实可交互**的（点击、输入、拖拽、开关等），而非静态截图。

## 项目结构

```text
index.html                    学习库入口（知识地图 + demo + AI 协作练习）
docs/全栈学习库优化设计.md     产品定位、模块顺序和验收标准
assets/                       少量静态资源
project.html                  兼容入口，自动回到 index.html 的项目区
examples/trip-manager/        第一阶段可运行全栈示例（FastAPI + SQLite + 原生前端）
```

## 技术栈

- 原生 HTML + CSS + JavaScript（单文件，零依赖）
- 无构建步骤，直接打开即可体验；后端请求与报文 demo 在浏览器内模拟
- 每个重点 demo 都遵循“先理解 → 自己判断 → AI 任务 → 验收结果”的学习顺序
